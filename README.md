# La última pupusa

## 1. Nombre y frase

Un juego de turnos contra la máquina: quedan pupusas en el plato, cada quien agarra una, dos o tres, y el que agarra la última pierde.

## 2. Qué hace y cómo se usa

Muestra pupusas disponibles y permite jugar por turnos contra la máquina.
Elegí Fácil o Difícil y agarrá 1, 2 o 3 pupusas con los botones o las teclas 1, 2 y 3.
La tecla R reinicia la partida; quien agarra la última pupusa pierde.

## 3. Enlace para abrirlo

[Abrir La última pupusa](http://localhost:5173/)

Para abrir el enlace, primero iniciá el servidor local con los comandos de la sección siguiente.

## 4. Cómo correrlo en otra máquina

Requisitos: Node.js y npm instalados.

```sh
npm install
npm run dev
```

Abrí la dirección local que muestre Vite en la terminal (normalmente `http://localhost:5173/`). Para ejecutar las pruebas:

```sh
npm test
```
